# 🦈 Sharkie

Sharkie is a 2D browser game developed with **HTML, CSS, and JavaScript** using the HTML5 Canvas.

The player controls Sharkie through an underwater world, fights enemies, collects items, and eventually faces a dangerous end boss.

## 🎮 Gameplay

During the game you can:

- 🏊 Swim through the underwater world
- 🫧 Shoot poison bubbles
- 👊 Attack enemies with a fin slap
- 🪙 Collect coins
- 🧪 Collect poison bottles
- 🐟 Fight different underwater enemies
- 🦈 Face an end boss
- ❤️ Keep an eye on Sharkie's health

## 🕹️ Controls

| Key | Action |
| --- | --- |
| `←` | Swim left |
| `→` | Swim right |
| `↑` | Swim up |
| `↓` | Swim down |
| `SPACE` | Fin slap attack |
| `D` | Shoot poison bubble |

## 🧩 Project Structure

The game is structured using object-oriented JavaScript.

Different classes are responsible for individual parts of the game, including:

- Character
- Enemies
- End boss
- Collectable objects
- Throwable objects
- Status bars
- Sounds
- World
- Keyboard controls

## 🔊 Sound

Sharkie includes different sound effects for:

- Swimming
- Attacking
- Taking damage
- Collecting items
- Sleeping
- Enemy interactions
- End boss fight

## 📱 Responsive Design

The game interface adapts to different screen sizes while maintaining the original aspect ratio of the game canvas.

## 🚀 Installation

Clone the repository:

```bash
git clone <repository-url>
```

Open the project folder:

```bash
cd sharkie
```

Then open `index.html` in your browser.

For development, using **Live Server** in Visual Studio Code is recommended.
